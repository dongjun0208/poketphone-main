# poketphone
휴대폰 그만하자. 포켓폰 입니다.
# 2026 -08-08
## 프로젝트 소개
-스마트폰 과몰입을 방지하기 위한 디지털 앱입니다.
-스마트폰을 뒤집어 놓는 동안 집중 알이 부화하여 다양한 포켓몬을 모을 수 있습니다.
## 현재 기능
집중 모드: 핸드폰을 화면이 아래로 가도록 뒤집어 놓으면 타이머가 작동합니다.
알 부화 시스템:집중 시간이 누적되거나 목표 시간을 달성하면 알이 포켓몬으로 부화합니다.
포켓몬 도감:부화시킨 포켓몬들을 도감에 수집할수있습니다.

## 실행 방법
파일을 설치하고 실행을하면 뒤집기 버튼을 누르고 휴대폰을 뒤집으면 알이 부화합니다.
